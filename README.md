# Tempo Scheduling App

A full-stack scheduling platform built with:

- Next.js (App Router)
- Supabase (database)
- Clerk (authentication)

## Features
- User authentication (Clerk)
- Role-based routing (manager / employee)
- Shift scheduling system
- Availability management
